# USB AI Technician – טכנאי מחשבים נייד עם בינה מלאכותית

**כלי תחזוקה למחשב שיושב כולו על דיסק און קי.** מחברים את ה-USB לכל מחשב Windows, לוחצים פעמיים על `Start.cmd`, והכלי:

1. **מנקה את המחשב**: מציג את כל התוכנות המותקנות, הבינה המלאכותית מסמנת מה מיותר, **הכלי שואל אותך אילו תוכנות להשאיר**, מסיר את השאר ומנקה קבצים זמניים ישנים.
2. **מתקין תוכנות חדשות** מתיקיית `Installers` שעל ה-USB, בהתקנה שקטה כשאפשר.
3. **מעדכן את Windows**, ואחר כך **מבטל עדכונים אוטומטיים ומשאיר רק עדכוני אבטחה**.

המודל הוא [gpt-oss-20b של OpenAI](https://huggingface.co/openai/gpt-oss-20b). הוא **רץ מקומית מה-USB** בעזרת [llama.cpp](https://github.com/ggml-org/llama.cpp), בלי אינטרנט ובלי ענן, ונגיש רק מתוך המחשב עצמו (`127.0.0.1`).
**לא מותקן כלום על המחשב.** הלוגים, הגיבויים והקבצים הזמניים של הכלי נשמרים על ה-USB.

## התחלה מהירה

### מה צריך

| | |
|---|---|
| **דיסק און קי** | 32GB ומעלה, **מפורמט ל-exFAT או NTFS** (FAT32 לא מסוגל לשמור את קובץ המודל, שגודלו 12GB). מומלץ USB 3 |
| **מחשב היעד** | Windows 10 או 11, הרשאות מנהל |
| **בשביל ה-AI** | 16GB זיכרון RAM ומעלה. במחשבים חלשים יותר הכלי עובד גם בלי AI (`Start.cmd -NoAI`) |

### שלב 1 – הכנת ה-USB (פעם אחת, במחשב שלך)

1. מורידים את הגרסה האחרונה מ-[**Releases**](https://github.com/dor2500/usb-ai-technician/releases/latest) ומחלצים ל-USB:
   * `usb-ai-technician-vX.Y.Z-with-llama.cpp.zip`: **מומלץ**. כולל גם את llama.cpp, כך שנשאר להוריד רק את המודל.
   * `usb-ai-technician-vX.Y.Z.zip`: הכלי בלבד.

   המודל עצמו (12GB) לא נמצא ב-Releases, כי GitHub מגביל כל קובץ ל-2GB. `Setup-USB.cmd` מוריד אותו.
2. מריצים את **`Setup-USB.cmd`** מתוך ה-USB. הוא:
   * מוריד את גרסת llama.cpp העדכנית ל-Windows אל `bin\`. זו גרסת Vulkan, שעובדת עם כרטיסי מסך של NVIDIA, AMD ו-Intel, ובלי כרטיס מסך עוברת למעבד.
   * מוריד את המודל **gpt-oss-20b** (בערך 12GB) אל `models\`. אם ההורדה נקטעת, אפשר להמשיך מאותה נקודה.
   * בודק את שתי ההורדות עם **SHA-256**.

### שלב 2 – הוספת תוכנות להתקנה

מעתיקים קבצי התקנה (`.exe`, `.msi`, `.msix` ...) לתיקייה **`Installers`**.
אפשר להגדיר פרמטרים להתקנה שקטה לכל קובץ (פרטים ב-[Installers/README.md](Installers/README.md)).

### שלב 3 – שימוש בכל מחשב

מחברים את ה-USB ולוחצים פעמיים על **`Start.cmd`**. הכלי יבקש הרשאות מנהל ויפתח תפריט:

| מקש | פעולה |
|---|---|
| **1** | ניקוי המחשב: ה-AI מציע מה להסיר, ואתה בוחר מה להשאיר |
| **2** | התקנת תוכנות מתיקיית Installers |
| **3** | עדכון Windows ומעבר לעדכוני אבטחה בלבד |
| **4** | כל השלושה ברצף |
| **5** | שאלה חופשית לטכנאי ה-AI (גם בעברית) |
| **6** | ביטול נעילת העדכונים, כלומר החזרת ההגדרות המקוריות |

אפשרויות שורת פקודה:

<div dir="ltr">

```powershell
Start.cmd -Action All     # הכול ברצף, בלי תפריט
Start.cmd -NoAI           # בלי מודל (למחשבים עם מעט זיכרון)
Start.cmd -DryRun         # מצב ניסיון: מראה מה היה קורה בלי לשנות כלום
```

</div>

## מה זה עושה

### 1. ניקוי המחשב

* קורא את רשימת התוכנות המותקנות מהרישום, כולל אפליקציות Microsoft Store שאפשר להסיר.
* **דרייברים, ספריות מערכת ורכיבי Windows אף פעם לא מוצעים להסרה.** למשל Visual C++, .NET, WebView2, דרייברים של מסך, שמע וצ'יפסט, ו-Defender. הרשימה נמצאת ב-[`config/protected.json`](config/protected.json).
* **gpt-oss-20b** עובר על הרשימה ומסמן כל תוכנה כ-`remove` (תוכנות זבל של יצרן, גרסאות ניסיון, סרגלי כלים, "מאיצי מחשב" וכדומה), `keep` או `ask`, עם הסבר קצר.
* מוצגת טבלה צבעונית, **ואתה בוחר מה להשאיר**:
  `k 3,5-7` להשאיר · `r 9` להסיר · `ai` לחזור להמלצת ה-AI · `keepall` להשאיר הכול · `go` להמשיך
* לפני ההסרה צריך להקליד `YES`. הכלי יוצר **נקודת שחזור מערכת** ומסיר בשקט כשאפשר. תוכנות שאין להן הסרה שקטה פותחות את חלון ההסרה הרגיל שלהן.
* בסוף הכלי מציע למחוק **קבצים זמניים בני יותר מיום**.

### 2. התקנת תוכנות מה-USB

* מזהה אוטומטית את סוג קובץ ההתקנה: **MSI, MSIX, Inno Setup, NSIS, WiX**, ומתקין בשקט עם הפרמטרים המתאימים.
* קובץ שסוגו לא מזוהה נפתח בחלון ההתקנה הרגיל.
* בסוף מוצג דו"ח ברור: הותקן, צריך הפעלה מחדש, בוטל וכדומה.

### 3. עדכון Windows ונעילה לעדכוני אבטחה בלבד

**שלב א':** מתקין את כל העדכונים הממתינים דרך ממשק Windows Update שמובנה ב-Windows, בלי להתקין שום מודול. שדרוגי גרסה (Feature Updates) מדולגים.

**שלב ב':** מגדיר את מדיניות Windows Update כך:

| הגדרה | תוצאה |
|---|---|
| `TargetReleaseVersion` | **נשארים בגרסת Windows הנוכחית**, בלי שדרוגי גרסה |
| `ExcludeWUDriversInQualityUpdate = 1` | **אין עדכוני דרייברים** אוטומטיים |
| `AUOptions = 4` | **עדכוני האבטחה החודשיים ממשיכים להגיע ולהתקין לבד** |
| `NoAutoRebootWithLoggedOnUsers = 1` | **אין הפעלה מחדש בכפייה** כשמישהו מחובר |

ההגדרות המקוריות נשמרות **על ה-USB** בתיקייה `backups\`, ואפשרות **6** בתפריט מחזירה אותן בדיוק כמו שהיו.
רוצים לכבות עדכונים אוטומטיים **לגמרי**? משנים ל-`"mode": "ManualOnly"` בקובץ [`config/settings.json`](config/settings.json).

> שימו לב: ב-Windows 10/11 אין יותר חבילות נפרדות של "אבטחה בלבד". תיקוני האבטחה מגיעים בעדכון המצטבר החודשי, והוא נשאר אוטומטי. מה שמבוטל הוא שדרוגי גרסה, עדכוני דרייברים והפעלה מחדש בכפייה.

## בטיחות

* ✅ **נקודת שחזור** לפני הסרת תוכנות ולפני התקנת עדכונים
* ✅ צריך להקליד **`YES`** לפני כל הסרה
* ✅ **רשימה מוגנת**: דרייברים, ספריות מערכת ותוכנות אבטחה לעולם לא מוצעים להסרה
* ✅ **מצב ניסיון (`-DryRun`)** שמראה מה היה קורה בלי לשנות כלום
* ✅ **ביטול** של נעילת העדכונים (תפריט 6), עם גיבוי של ההגדרות המקוריות
* ✅ **לוג** של כל פעולה בתיקייה `logs\` על ה-USB
* ✅ **ה-AI רק ממליץ.** הוא לא מריץ שום פקודה, וכל שינוי במחשב קורה רק אחרי האישור שלך

השתמשו בכלי רק במחשבים שלכם או במחשבים שמותר לכם לנהל.

## שאלות נפוצות

<details>
<summary><b>ההתקנה אומרת שהכונן הוא FAT32</b></summary>

FAT32 לא יכול לשמור קבצים גדולים מ-4GB. מגבים את ה-USB, מפרמטים ל-**exFAT** (קליק ימני על הכונן ← Format ← exFAT), מעתיקים חזרה ומריצים שוב את `Setup-USB.cmd`.
</details>

<details>
<summary><b>מופיעה הודעת "Windows protected your PC"</b></summary>

קבצים שהורדו כ-ZIP מסומנים כקבצים מהאינטרנט. לוחצים על *More info ← Run anyway*.
</details>

<details>
<summary><b>ה-AI איטי מאוד או לא עולה</b></summary>

המודל צריך בערך 16GB זיכרון. במחשבים חלשים מריצים `Start.cmd -NoAI`, וכל שלוש הפעולות עובדות גם בלי AI. פשוט בוחרים לבד מה להסיר. פרטים על שגיאות נמצאים ב-`logs\llama-server.err.log`.
</details>

<details>
<summary><b>בהגדרות כתוב "Some settings are managed by your organization"</b></summary>

כך Windows מציג את מדיניות העדכונים משלב 3. אפשרות 6 בתפריט מבטלת אותה.
</details>

<details>
<summary><b>צריך אינטרנט?</b></summary>

ה-AI לא צריך אינטרנט. ל-Windows Update כמובן צריך, ו-`Setup-USB.cmd` צריך אינטרנט פעם אחת כדי להוריד את llama.cpp ואת המודל.
</details>
